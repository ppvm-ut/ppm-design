Добавить HTML-прототип

Положите файл в prototypes/название.html или соберите папку prototypes/название/index.html с ресурсами рядом.

После отправки в main и успешной публикации файл появится здесь автоматически. Название берётся из <title>, описание и статус — из метатегов HTML.
