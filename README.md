# ППМ / Design

HTML-прототипы и общий каталог: https://ppvm-ut.github.io/ppm-design/

Каждый прототип открывается независимо, например:
https://ppvm-ut.github.io/ppm-design/balance-transfer.html

## Первая публикация

1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. После отправки файлов в `main` дождитесь успешного workflow **Publish prototypes to GitHub Pages**. Если первый запуск произошёл до включения Pages, запустите workflow повторно через **Actions → Run workflow**.

## Добавление и обновление прототипов

Новые HTML-прототипы сохраняйте в `PPM_Codex/PPM_Design/prototypes/`. [Инструкция по публикации](prototypes/README.md). Существующие прототипы в корне сохраняют свои адреса. При необходимости прототип со своими ресурсами можно разместить в отдельной подпапке. Используйте относительные ссылки на ресурсы; `index.html` в корне зарезервирован для каталога.

После commit и push в `main` GitHub Actions заново собирает каталог и публикует все прототипы. Новые HTML автоматически появляются в каталоге. Для них берётся название из `<title>`; папки становятся разделами. Само сохранение файла на компьютере не запускает публикацию.

## Локальная проверка

Нужен Python 3, сторонние пакеты не требуются:

```sh
python3 scripts/build_pages.py
python3 -m http.server 8000 --directory _site
```

Откройте http://localhost:8000/. Сборка также обновляет корневой `index.html`, который можно открыть напрямую. Он генерируется из `scripts/build_pages.py`; изменения оформления каталога вносите в шаблон этого скрипта.

В Pages публикуются HTML и веб-ресурсы. Инструкции, Markdown-документы, `work/`, скрытые файлы и исходники сборки в сайт не попадают. В публичном Git-репозитории отслеживаемые файлы доступны посетителям репозитория.

## Изоляция

Страницы имеют независимые DOM, CSS и JavaScript. Домен и браузерное хранилище общие: используйте уникальные ключи `localStorage` и `sessionStorage` для каждого прототипа. Это каталог публичных демонстрационных интерфейсов.

## Известные недостающие ресурсы

`plastic-gift.html` ссылается на `start.mp4`, которого пока нет в проекте. Чтобы заработало видео, добавьте этот файл рядом с прототипом. Сборка сообщает о недостающих локальных ресурсах, а каталог помечает такие страницы.
